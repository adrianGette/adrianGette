### ⭐ Featured project

#### [Stock Simple](https://github.com/adrianGette/stock-simple): point of sale & inventory for small shops

Per-size sales, bulk price updates with preview, sales and margin reports, and three roles (owner, manager, cashier) that each see a different app.

- **Atomic sales in PostgreSQL:** it never sells stock it doesn't have, and a retry never charges twice (a test fires 12 concurrent sales at 5 units and requires exactly 5 to succeed).
- **Monorepo** where the web app and the API share the same Zod schemas and pricing functions.
- **Server-side security:** role-based permissions, tenant isolation, rotating refresh tokens in httpOnly cookies and rate limiting.
- **80+ tests** (unit, API against a real Postgres, Playwright on desktop and mobile) running in GitHub Actions, with Docker and a free deployment on Netlify + Render + Neon.

`React 19` `TypeScript` `NestJS` `PostgreSQL` `Prisma` `Zod` `TanStack Query` `Playwright` `Docker`
