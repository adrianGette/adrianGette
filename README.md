### ⭐ Proyecto destacado

#### [Stock Simple](https://github.com/adrianGette/stock-simple): punto de venta y control de stock para comercios chicos

Ventas por talle, aumentos masivos de precios con vista previa, reportes de ventas y márgenes, y tres roles (dueña, encargado y cajera) que ven una aplicación distinta según sus permisos.

- **Ventas atómicas en PostgreSQL:** nunca vende stock que no hay y un reintento nunca cobra dos veces (un test lanza 12 ventas simultáneas sobre 5 unidades y exige exactamente 5 aprobadas).
- **Monorepo** donde la web y la API comparten los mismos esquemas Zod y funciones de precios.
- **Seguridad en el servidor:** permisos por rol, aislamiento entre comercios, refresh token rotativo en cookie httpOnly y rate limiting.
- **Más de 80 tests** (unitarios, de API contra Postgres real y Playwright en escritorio y celular) en CI con GitHub Actions, con Docker y deploy gratuito en Netlify + Render + Neon.

`React 19` `TypeScript` `NestJS` `PostgreSQL` `Prisma` `Zod` `TanStack Query` `Playwright` `Docker`

**[Ver demo](https://stock-simple-adrian.netlify.app/)** · **[Ver código](https://github.com/adrianGette/stock-simple)**
